# Stream Feature Embeddings v1

Deterministic structured numeric embeddings for stream events, relation edges, controls, and comparison rows.

- event embeddings: **6795**
- relation embeddings: **89**
- control embeddings: **28**
- comparison embeddings: **16**
- all rows: **6928**

## Use

These rows can be used for clustering, MLP watcher training, attention-over-events, anomaly scoring, and fast dashboards.
