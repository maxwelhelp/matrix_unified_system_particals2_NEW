# Что считает нейронка

Это новая главная папка для направления: **не просто как сеть вычисляет, а что именно она считает физически / логически / программно**.

Старые документы не удаляются. Эта папка — нормальная навигация поверх текущих `docs/`, `reports/latest/`, `tools/`, `scripts/`.

## Две основные ветки

```text
01_общая_задача_что_считает_нейронка
  Родная папка старого направления: декомпиляция сети/матриц/голов в псевдокод.

02_текущая_задача_particlenet_hqql_tbl
  Текущая задача: ParticleNet, JetClass, Hqql/Tbl, lepton/core isolation, physics mechanism.
```

## Правило документации

Каждый новый отчёт должен попадать в одну из категорий:

```text
method       — как устроен метод / инструмент
finding      — что уже найдено
experiment   — что запускали и какие числа получили
residual     — что объяснено explicit observables, что осталось
roadmap      — что делать дальше
handoff      — как ввести следующего агента/человека в курс дела
```

## Главная текущая формулировка

```text
Мы ищем не просто important features, а вычислительные маршруты сети,
которые имеют физический или логический смысл.
```

Для текущей ParticleNet-задачи самый сильный результат сейчас:

```text
ParticleNet implicitly uses lepton/core isolation inside jet
as a discriminant for Hqql/Tbl ambiguity.
```

Но residual остаётся: explicit isolation/KNN/missing-pT surrogate ещё не полностью воспроизводит поведение ParticleNet.
